# CASE093 — 소결로가 삼킨 인증
> 마스터를 쓰기 위한 **이야기 소스**다. 서버는 이 파일을 읽지 않는다 —
> `app/game.ts`의 케이스 로더가 `*.master.json`만 훑기 때문에 번들에도
> 들어가지 않는다. 여기 적힌 것을 재료로 같은 폴더의 `.master.json`을 채운다.

## 배경

3D프린팅 의료보형물 제작소 '바이오프린트랩'의 소결·검수 작업동. 의료기기 제조인증 갱신 심사를 사흘 앞둔 밤, 인증 심사용 마지막 소결 작업이 한창이던 늦은 밤, 수석 제조품질엔지니어 조하덕이 소결로실 안에서 쓰러진 채 발견돼 병원으로 옮겨졌으나 사망이 확인된다.

## 톤

의료기기 인증 갱신 심사를 사흘 앞둔 초조함과, 정밀 제조 공정 뒤에 숨은 배신이 주는 서늘함이 뒤섞인 분위기.

## 탐정의 진입

- 경로: `travel`

탐정은 다른 지역으로 향하는 길에 바이오프린트랩 앞을 지나다 열린 셔터 사이로 몰려나오는 사람들을 보고 걸음을 멈췄다.

## 진실

**진범**: 구환재 (CH03)
**공범**: 없음

### 동기

구환재는 소결 온도와 유지 시간이 규격에 못 미치는 배치를 정상 통과로 기재해 인증서류를 채워 왔다. 조하덕이 소결기록과 실제 검수 데이터를 대조하다 그 어긋남을 짚어내고 인증심사관에게 그대로 넘기겠다고 나서면서, 사흘 뒤로 다가온 갱신 심사가 구환재를 궁지로 몰아넣었다.

### 수법

소결로실의 적재암은 로 안팎으로 트레이를 옮기는 자동 로봇 팔로, 사람이 로 앞에 서면 즉시 정지하도록 안전센서가 달려 있었다. 구환재는 그날 밤 조하덕이 늘 마지막 배치를 직접 로에서 꺼낸다는 걸 알고, 적재암 안전센서 배선을 미리 뽑아 두었다. 조하덕이 소결 배치를 꺼내려 로 앞에 다가선 순간 적재암이 정지하지 않고 그대로 회전해 그의 몸을 강하게 들이받았고, 그는 로 옆 프레임에 부딪혀 쓰러졌다.

### 결정적 시각·장소

D-1, 21:00, L03 소결로실에서 안전센서 배선 제거 / D-1, 21:40, L03 소결로실에서 적재암 충돌 / D-1, 22:10, L03 소결로실에서 배선 복구.

### 은폐

구환재는 사고 직후 뽑았던 안전센서 배선을 다시 꽂아 넣고, 정비 이력에는 센서가 원래부터 정상 작동 중이었던 것으로만 기재해 두었다.

## 이 소스가 마스터의 어디로 가는가

| 소스 | 마스터 |
| --- | --- |
| 배경 | `locations[]`, `characters[].role`, `relationships[]` |
| 톤 | `opening_scene.narrative`, `ending_scene.narrative` |
| 탐정의 진입 | `opening_scene.narrative`, `opening_scene.detective_entry_time` |
| 동기 | `contradiction_stages`, `red_herrings`, `final_deduction.motive` |
| 수법 | `actual_timeline`, `evidence[]`, `final_deduction.method` |
| 결정적 시각·장소 | `actual_timeline`, `final_deduction.key_connection` |
| 은폐 | `actual_timeline`의 은폐 항목, `red_herrings`, `characters[].initial_claims` |
`full_truth.responsible_character_id`만은 마스터에 그대로 남는다 — 진범 판정,
타임라인 필터(`filterSafeTimelineFacts`), 대립 단계가 전부 그 값에 걸려 있다.
