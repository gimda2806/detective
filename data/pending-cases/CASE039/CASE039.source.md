# CASE039 — 서버실이 삼킨 마지막 로그
> 마스터를 쓰기 위한 **이야기 소스**다. 서버는 이 파일을 읽지 않는다 —
> `app/game.ts`의 케이스 로더가 `*.master.json`만 훑기 때문에 번들에도
> 들어가지 않는다. 여기 적힌 것을 재료로 같은 폴더의 `.master.json`을 채운다.

## 배경

전국 인디 보드게임 디자인 공모전 결선 발표를 사흘 앞둔 보드게임 카페 겸 개발 스튜디오 '주사위정원'. 결선 진출작 최종 리허설이 한창이던 저녁, 수석 플레이테스터가 서버실 안에서 의식을 잃은 채 발견된다.

## 톤

결선 발표를 앞둔 스튜디오 특유의 긴장감과 아마추어 보드게이머들의 왁자한 분위기가 뒤섞인 공간.

## 탐정의 진입

- 경로: `personal_appointment`

탐정은 몇 주 전부터 예약해 둔 친구들과의 개인 보드게임 모임 때문에 '주사위정원'을 찾았다가, 서버실 쪽에서 벌어진 소란과 마주친다.

## 진실

**진범**: 백재훈 (CH02)
**공범**: 없음

### 동기

백재훈은 몇 달 전 공모전 사전 검토위원으로 참여했다가 익명 응모작의 핵심 매커니즘을 몰래 베껴 자신의 결선 진출작에 적용했다. 수석 플레이테스터 우다경이 두 게임의 룰북을 비교하다 결정적 유사성을 발견해 공모전 사무국에 제보할 준비를 하자, 백재훈은 발각이 임박했음을 느꼈다.

### 수법

백재훈은 사고 당일 저녁 설비실 소화설비 제어반을 조작해 서버실 이산화탄소 소화가스가 원격으로도 수동 방출되도록 만들고, 저녁 설비 점검을 자기가 이미 돌았다며 점검 일지에 대신 서명해 서다온이 그날 설비실에 들어가지 않게 했다. 우다경이 빌드 백업을 확인하러 서버실에 들어가자 원격 스위치로 가스를 방출시켜 문이 자동으로 잠기게 만들었다.

### 결정적 시각·장소

18:40, L04 설비실에서 제어반 조작 / 18:50, L04 점검 일지에 대신 서명 / 19:15~19:23, L06 서버실에서 우다경이 소화가스에 질식.

### 은폐

백재훈은 사고 소식이 전해지자마자 개발실 컴퓨터에서 대조표와 룰북 비교 파일들을 삭제하고, 소화설비 오작동을 노후 장비 탓으로 몰아가려 한다.

## 이 소스가 마스터의 어디로 가는가

| 소스 | 마스터 |
| --- | --- |
| 배경 | `locations[]`, `characters[].role`, `relationships[]` |
| 톤 | `opening_scene.narrative`, `ending_scene.narrative` |
| 탐정의 진입 | `opening_scene.narrative`, `opening_scene.detective_entry_time` |
| 동기 | `contradiction_stages`, `red_herrings`, `final_deduction.motive` |
| 수법 | `actual_timeline`, `evidence[]`, `final_deduction.method` |
| 결정적 시각·장소 | `actual_timeline`, `final_deduction.key_connection` |
| 은폐 | `actual_timeline`의 은폐 항목, `red_herrings`, `characters[].initial_claims` |
`full_truth.responsible_character_id`만은 마스터에 그대로 남는다 — 진범 판정,
타임라인 필터(`filterSafeTimelineFacts`), 대립 단계가 전부 그 값에 걸려 있다.
