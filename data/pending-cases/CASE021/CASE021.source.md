# CASE021 — 새 이름표가 가린 진실
> 마스터를 쓰기 위한 **이야기 소스**다. 서버는 이 파일을 읽지 않는다 —
> `app/game.ts`의 케이스 로더가 `*.master.json`만 훑기 때문에 번들에도
> 들어가지 않는다. 여기 적힌 것을 재료로 같은 폴더의 `.master.json`을 채운다.

## 배경

글로벌 화장품 브랜드 신제품 캠페인 메인 화보 촬영을 사흘 앞둔 독립 촬영 스튜디오 '루멘'. 이른 아침, 수석 조명디렉터가 촬영홀에서 낙하한 조명 리그에 깔린 채 발견된다.

## 톤

이른 아침 촬영 스튜디오의 정적과 캠페인을 앞둔 긴장이 뒤섞인 분위기.

## 탐정의 진입

탐정은 최근 개업한 지인의 편집숍 축하 방문차 근처를 찾았다가, 골목 안쪽 촬영 스튜디오 '루멘' 앞으로 사람들이 황급히 몰려드는 것을 보고 그쪽으로 걸음을 옮긴다.

## 진실

**진범**: 오태겸 (CH03)
**공범**: 없음

### 동기

오태겸은 모델 에이전시 대표 여진서로부터 캐스팅 대가를 받고, 이번 캠페인 메인 모델 오디션 결과를 조작해 여진서 소속 모델을 1위로 바꿔치기했다. 수석 조명디렉터 남도현이 정산 자료를 정리하다 점수 조작 정황을 발견하고 캐물었고, 촬영 전까지 해명하지 않으면 브랜드 측에 모든 것을 알리겠다고 경고하자, 캠페인 무산과 커리어 붕괴를 막기 위해 그를 살해했다.

### 수법

사건 전날 밤, 오태겸은 장비보관실에서 메인 조명 리그 고정 클램프를 몰래 풀어두고 정비 일지의 최근 점검 기록을 조작했다. 다음 날 새벽 남도현이 홀로 남아 리그 최종 점검을 하다 클램프가 완전히 풀리며 낙하한 리그에 깔렸다. 오태겸은 낙하한 리그 옆에 새 안전점검 태그를 걸어두고 공구함 배치를 바꿔 사고처럼 위장했다.

### 결정적 시각·장소

전날 밤 11시~11시반, L03 장비보관실에서 클램프·정비 일지 조작 / 새벽 5시10분, L02 메인 촬영홀에서 리그 낙하로 남도현 사망.

### 은폐

오태겸은 리그 노후로 인한 사고사라고 둘러대고, 새 안전점검 태그와 조작된 정비 일지로 현장을 정상 점검이 있었던 것처럼 꾸몄다.

## 이 소스가 마스터의 어디로 가는가

| 소스 | 마스터 |
| --- | --- |
| 배경 | `locations[]`, `characters[].role`, `relationships[]` |
| 톤 | `opening_scene.narrative`, `ending_scene.narrative` |
| 탐정의 진입 | `opening_scene.narrative`, `opening_scene.detective_entry_time` |
| 동기 | `contradiction_stages`, `red_herrings`, `final_deduction.motive` |
| 수법 | `actual_timeline`, `evidence[]`, `final_deduction.method` |
| 결정적 시각·장소 | `actual_timeline`, `final_deduction.key_connection` |
| 은폐 | `actual_timeline`의 은폐 항목, `red_herrings`, `characters[].initial_claims` |
`full_truth.responsible_character_id`만은 마스터에 그대로 남는다 — 진범 판정,
타임라인 필터(`filterSafeTimelineFacts`), 대립 단계가 전부 그 값에 걸려 있다.
