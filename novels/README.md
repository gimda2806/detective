# 소설판 — 사건 마스터를 한 편의 추리소설로

`data/pending-cases/<CASE_ID>/<CASE_ID>.master.json`을 번호순으로 읽어, 한 사건을
처음부터 끝까지 읽히는 단편 추리소설로 옮긴 것들이다. **런타임은 이 폴더를 읽지
않는다** — 게임은 `.master.json`만 본다.

## 이 폴더가 마스터와 다른 점

| | 마스터 | 소설 |
| --- | --- | --- |
| 형태 | 플레이어가 고를 수 있는 행동과 규칙표 | 처음부터 끝까지 한 방향으로 읽히는 산문 |
| 순서 | 플레이어가 정한다 | 작성자가 정한다 (진상이 드러나는 순서로) |
| 빈칸 | GM(모델 또는 규칙표)이 그 자리에서 메운다 | 원고가 미리 메워 두어야 한다 |
| 시점 | 2인칭('당신은')이 섞여 있다 | 3인칭 탐정 시점으로 통일 |

## 규칙

1. **진상은 바꾸지 않는다.** 진범·동기·수법·시각·인물의 말투와 호칭은 마스터 그대로다.
   탐정은 한지우에게 반말, 한지우는 탐정에게 반존대(`-요`), 다른 인물에게는 둘 다 존댓말.
2. **오프닝과 엔딩의 대사는 원문을 그대로 쓴다.** 소설이 채우는 것은 그 사이다.
3. **채운 것은 전부 각 파일 맨 아래 「덧붙인 것」 표에 적는다.** 무엇을, 왜 넣었는지.
   마스터에 없던 사실을 만든 경우에는 그것이 진상을 건드리지 않는다는 것도 함께 적는다.
4. 덧붙이는 재료는 **되도록 마스터 안에 이미 있는 것**에서 끌어온다 —
   `world_fact`만 있고 화면에 나오지 않는 항목, `lingering_thread`처럼 마스터가 열어만 둔 실,
   인물의 `voice_profile`·`comic_tell`처럼 성격은 정해져 있는데 쓰일 자리가 없던 것.
