# how_to_clear 가 사실·진술 id 만 부르는 레드헤링

레드헤링 602개 중 **87개** · 사건 79건 (2026-09 기준)

## 이건 어떤 자리인가

증거 카드(`E##`)는 안 부르고 사실(`F-`)·진술(`S-`)·단계(`C##`) id 만 부른다. 런타임은
그 id 가 전부 `heard_statements` 에 들어왔는지를 본다 — **그 말을 들었는가**(장소
관찰 사실 `F-L##-OBS-##` 은 그 방을 둘러봤을 때 같은 목록에 들어온다). 「다 물어봤나」로
떨어지는 194개보다 낫다. 무엇을 들어야 하는지가 정해져 있으니까.

갈리는 것은 **누구 입에서 나오는 말인가**다.

| 부르는 것 | 개수 | 뜻 |
|---|---|---|
| **본인 진술만** | **13** | 「본인이 아니라고 했다」 — 본인 카드와 같은 모양, 손봐야 할 것 |
| 장소 관찰 사실이 낌 (남의 진술은 없음) | 69 | 방을 둘러봐야 하므로 성립한다 |
| 남의 진술이 낌 | 5 | 두 사람을 오가야 하므로 성립한다 |

`hidden_until` 로 잠긴 진술을 부르는 것 6개 — 잠금을 풀어야 들을 수 있으니 그 자체가 순서다.

「주인공」은 `surface_suspicion` 에 처음 나오는 인물 이름으로 **추측**한 것이다.
