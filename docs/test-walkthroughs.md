# 테스트용 공략집 (CASE023 / CASE010 / CASE115 / CASE072 / CASE043)

런타임 검증용 스포일러 문서. 마스터 JSON에서 자동 추출했다 — 사람이 옮겨 적은 값이 아니므로 실제 게임 판정과 어긋나지 않는다.

웹 버전(복사 버튼·정답 접기): https://claude.ai/code/artifact/dea06ade-38c6-4872-bda5-857f7dc3e61d

## 쓰는 법

- **증거 획득**: 아래 `입력` 문구를 그대로 치는 게 가장 확실하다. 런타임이 플레이어 입력에서 그 장소 세부 행동의 단어를 찾아 판정하므로, 동의어(예: 제안서→계약서)를 쓰면 막힐 수 있다.
- **증거 제시**: 자유 입력 대신 **증거 피커로 골라서** 제시한다. 조합이 맞으면 자동 추궁이 나가고 단계가 전진한다.
- **순서**: 증거를 먼저 모으고 대립 단계로 간다. 각 단계는 이전 단계에서 풀린 진술을 전제로 한다.
- **종결의 `F-…` 항목**: 수집하는 카드가 아니라 **대립 단계가 풀어주는 진술**이다. 해당 단계를 통과하면 자동으로 채워진다.

# CASE023 · 되감을 수 없는 트랙

**장르** 표절 은폐 / 감전사 위장 / 업계 신뢰  
**무대** 빈티지 오디오 수리점 겸 인디 레이블 사무실. 신보 발매를 하루 앞둔 밤, 표절 사실을 발견한 오디오 엔지니어가 테스트용 앰프를 만지다 감전사한 채 발견된다.

## 정답

- **범인** 임도경
- **수법** 임도경은 창고에서 시험용 앰프를 꺼내 작업실로 옮긴 뒤 접지 회로를 우회시켜 금속 섀시에 전류가 흐르도록 개조했다. 도재현이 퇴근 전 그 앰프를 테스트하다 감전되어 사망했다.
- **동기** 임도경은 발매를 하루 앞두고, 도재현이 신곡 샘플이 미공개 트랙과 파형이 일치한다는 표절 증거를 발견해 대표에게 알리려 한다는 사실을 알게 됐다. 표절이 알려지면 계약 자체가 깨질 상황이었다.
- **은폐** 임도경은 어젯밤 내내 사무실에 있었다고 주장하고, 도재현의 죽음을 앰프 오작동에 의한 사고로 몰아가려 한다.

## 장소 / 인물

**시작 위치** 레코드샵 프론트 `L01`

| 장소 | 인물 |
|---|---|
| **레코드샵 프론트** `L01` | 배소민(매장 견습생), 최윤슬(빈티지 오디오 동호회 회원), 하진우(매장 매니저 / 공동경영자) |
| **수리 작업실** `L02` | 임도경(수석 프로듀서) |
| **창고 겸 재고실** `L03` | — |
| **레이블 사무실** `L04` | 서한결(레이블 대표) |
| **뒷골목 하역구** `L05` | — |

| # | 필수 | 장소 | 입력 | 얻는 것 |
|---|---|---|---|---|
| E01 | ○ | 수리 작업실 | `테스트용 앰프 내부를 점검한다` | 앰프 배선 조작 흔적 |
| E02 | ○ | 창고 겸 재고실 | `창고 재고 이동 기록을 확인한다` | 창고 재고 이동 기록 |
| E03 | ○ | 레이블 사무실 | `마스터 음원 백업 폴더를 확인한다` | 파형 비교 캡처 |

| E05 | ○ | 면담 | `최윤슬에게 어젯밤 지나가다 본 것을 묻는다` | 동호회원의 뒷골목 목격담 |
| E06 | ○ | 수리 작업실 | `작업대 위 공구함을 확인한다` | 작업대 공구흔적 |

## 대립 단계

### C01 → `after_presence_admission`

- **상대** 임도경
- **제시할 증거** E04(매니저의 조명 목격담) + E05(동호회원의 뒷골목 목격담)
- **행동** 임도경에게 매니저의 조명 목격담과 동호회원의 뒷골목 목격담을 함께 제시하여, 어젯밤 계속 사무실에만 있었다는 주장과 비교한다.
- **풀리는 진술** 작업실 쪽에 잠깐 들렀던 것과 뒷문에서 담배를 피운 것은 인정하지만, 앰프에는 손대지 않았다고 발뺌한다.

### C02 → `after_tampering_admission`

- **상대** 임도경
- **제시할 증거** E02(창고 재고 이동 기록) + E06(작업대 공구흔적)
- **행동** 창고 재고 이동 기록과 작업대 공구흔적을 제시하여, 앰프에는 손대지 않았다는 주장과 비교한다.
- **풀리는 진술** 앰프를 옮기고 배선을 만진 것은 인정하지만, 실수로 잘못 연결했을 뿐 고의는 아니었다고 주장한다.

### C03 → `final_confession`

- **상대** 임도경
- **제시할 증거** E01(앰프 배선 조작 흔적) + E03(파형 비교 캡처)
- **행동** 배선 개조 흔적과 도재현의 파형 비교 캡처를 시간순으로 연결해 제시한다.
- **풀리는 진술** 발매 전날 표절 사실이 드러나는 것을 막기 위해, 고의로 접지 회로를 우회시켜 감전사고를 유도했다는 사실을 인정한다.

## 종결

- **필요 증거** E01, E02, E03, E04, E05, E06, F-CH02-02
- **필요 단계** C01, C02, C03
- **지목** 임도경
- **수법 진술** 테스트용 앰프의 접지 회로를 몰래 우회시켜 감전 사고를 유도했다.
- **동기 진술** 발매 전날 표절 사실이 드러나는 것을 막기 위해서였다.

# CASE010 · 식지 않은 한증막

**장르** 감금치사 / 오래된 협박 / 폐업 전야  
**무대** 재개발로 폐업을 하루 앞둔 산속 전통 온천 료칸. 폐업 전날 밤, 오랫동안 시설을 관리해 온 기사가 개인 한증막 안에 갇힌 채 열사병으로 숨진다.

## 정답

- **범인** 강태선
- **수법** 강태선은 폐업 전날 밤 노관식을 개인 한증막으로 불러 협상하는 척하다가, 문을 밖에서 잠그고 온도조절기를 최고치로 올려놓은 뒤 나왔다. 노관식은 밤새 한증막에 갇혀 열사병으로 사망했다.
- **동기** 강태선은 15년 전 무면허 오토바이 운전 중 사람을 치고 그대로 도주한 뺑소니 전력이 있다. 노관식은 우연히 그 사실을 알게 된 뒤 지난 몇 년간 강태선에게 입막음 대가로 매달 돈을 받아 왔다. 폐업으로 거액의 재개발 보상금이 강태선에게 들어온다는 것을 안 노관식은 마지막으로 3천만 원을 한 번에 요구하며, 주지 않으면 재개발 시행사와 마을 사람들에게 모두 알리겠다고 최후통첩했다.
- **은폐** 강태선은 보일러 노후로 인한 사고사처럼 보이도록 보일러실 표시 패널의 온도조절기 로그를 지우려 시도한다.

## 장소 / 인물

**시작 위치** 로비 `L01`

| 장소 | 인물 |
|---|---|
| **로비** `L01` | 강태선(료칸 총괄 지배인 / 3대째 상속자), 정우석(프런트 데스크 직원 / 야간 근무), 오세필(재개발 시행사 담당자) |
| **주방 겸 식당 홀** `L02` | 한미경(주방장 / 오래 근무한 직원) |
| **한증막** `L03` | — |
| **보일러실 겸 설비 관리실** `L04` | — |
| **관사 (피해자 숙소)** `L05` | 노유진(피해자의 딸 / 탐정 의뢰인) |

## 증거 수집

| # | 필수 | 장소 | 입력 | 얻는 것 |
|---|---|---|---|---|
| E01 | ○ | 관사 (피해자 숙소) | `책상 위 수첩을 확인한다` | 노관식의 수첩 |
| E02 | ○ | 한증막 | `한증막 도어락 기록을 확인한다` | 한증막 전자도어락 출입 기록 |
| E03 | ○ | 보일러실 겸 설비 관리실 | `온도조절기 백업 서버를 확인한다` | 온도조절기 백업 로그 |
| E04 | ○ | 보일러실 겸 설비 관리실 | `표시 패널 로그를 살펴본다` | 표시 패널 로그 삭제 흔적 |
| E05 | ○ | 면담 | `노유진에게 아버지 계좌의 최근 입출금 내역에 대해 묻는다` | 강태선의 계좌 송금 내역 |
| E06 | ○ | 면담 | `정우석에게 어젯밤 로비 밖으로 본 것을 묻는다` | 정우석의 야간 목격담 |

## 대립 단계

### C01 → `after_lock_admission`

- **상대** 강태선
- **제시할 증거** E02(한증막 전자도어락 출입 기록) + E06(정우석의 야간 목격담)
- **행동** 강태선에게 전자도어락 출입 기록과 정우석의 목격담을 제시하여, 밤새 로비에 있었다는 주장과 비교한다.
- **풀리는 진술** 한증막 쪽에 다녀온 것은 인정하지만, 노관식이 잘 있는지 확인하러 잠깐 들렀을 뿐이라고 주장한다. 문을 잠근 이유나 온도를 올린 사실은 부인한다.

### C02 → `after_temp_admission`

- **상대** 강태선
- **제시할 증거** E03(온도조절기 백업 로그) + E04(표시 패널 로그 삭제 흔적)
- **행동** 온도조절기 백업 로그와 표시 패널 삭제 흔적을 제시하여, 잠깐 들렀을 뿐이라는 주장과 비교한다.
- **풀리는 진술** 온도를 올린 것은 인정하지만, 홧김에 그런 것일 뿐 죽일 생각은 없었다고 주장한다. 문을 잠근 진짜 의도와 협박 관계는 여전히 부인한다.

### C03 → `final_break`

- **상대** 강태선
- **제시할 증거** E01(노관식의 수첩) + E05(강태선의 계좌 송금 내역)
- **행동** 노관식의 수첩과 강태선의 계좌 송금 내역을 시간순으로 연결해 제시한다.
- **풀리는 진술** 15년 전 뺑소니 전력을 노관식에게 들켜 협박당해 왔고, 폐업 정산금을 노린 마지막 요구에 몰려 그를 한증막에 가두고 온도를 올려 살해했음을 인정한다.

## 종결

- **필요 증거** E01, E02, E03, E04, E05, E06, F-CH01-01
- **필요 단계** C01, C02, C03
- **지목** 강태선
- **수법 진술** 한증막 문을 밖에서 잠그고 온도조절기를 최고치로 올려 노관식을 열사병으로 사망케 했다.
- **동기 진술** 15년 전 뺑소니 전력을 빌미로 한 협박에서 벗어나고 폐업 정산금을 지키기 위해 살해했다.

# CASE115 · 찾아가지 않은 이름

**장르** 미수령 위탁품 횡령·보험사기 은폐 / 도금실 시안화가스 중독사 위장  
**무대** VIP 고객 초청 감정 행사가 한창인 백화점 지하 명품관 종합 수선센터 '아틀리에 프리제'. 행사 중 자리를 비운 수석 수선사가 도금실 안에서 의식을 잃은 채 발견된다.

## 정답

- **범인** 곽지완
- **수법** 곽지완은 도금실 환기 덕트 입구를 미리 젖은 걸레와 테이프로 막아 두고, 처분 장부를 태워 없애자며 우석현을 도금실로 유인했다. 그런 다음 청산가리 성분 도금액과 산성 세척액을 한 통에 부어 시안화가스를 발생시켰고, 가스가 퍼지기 시작하자 먼저 방을 빠져나와 문을 밖에서 잠갔다.
- **동기** 곽지완은 수년간 장기 미수령 위탁품을 몰래 되팔고 고객에게는 분실·파손으로 보험 처리해 온 행각을 우석현과 함께 저질러 왔다. 최근 한 VIP 고객이 어머니의 유품 진주 목걸이를 찾으러 왔다가 이미 '분실 처리'됐다는 통보를 받고 크게 분노한 일을 계기로 우석현이 죄책감에 시달리다 이번 행사에서 외부 감정사 탁현서에게 모든 것을 자백하겠다고 통보하자, 이를 막기 위해 그를 살해했다.
- **은폐** 곽지완은 신아영에게 그 시각 계속 함께 있었다고 말해 달라 부탁해 거짓 알리바이를 만들었고, 우석현이 평소 세척액을 함부로 다뤘다는 인상을 심어 사고사로 위장하려 했다.

- **행동** 표유나의 진술을 제시하여, 그녀가 스스로 자리를 비운 것 같다는 주장과 비교한다.
- **풀리는 진술** 메시지를 보내 표유나를 다른 구역으로 이동시킨 것은 인정하지만 단순한 업무 요청일 뿐, 사고와는 무관하다고 주장한다.

### C03 → `final_break`

- **상대** 서지오
- **제시할 증거** E01(오토빌레이 제동 캠) + E03(정비 점검일지) + E04(작업실 파일 접근 기록) + E05(후원계약 제안서 사본) + E07(도경민의 진술) + E08(사무실 파일 삭제 기록)
- **행동** 제동 캠 조작 흔적, 점검일지 조작, 도면 파일 접근 기록, 후원계약 제안서, 도경민의 진술, 사고 후 파일 삭제 기록을 시간순으로 연결해 제시한다.
- **풀리는 진술** 도면을 도용해 온 사실이 드러날 위기에 몰려, 설민재를 오토빌레이로 유도하고 제동 캠을 무력화해 추락사로 위장했다는 사실을 인정한다.

## 종결

- **필요 증거** E01, E02, E03, E04, E05, E06, E07, E08, F-CH02-02
- **필요 단계** C01, C02, C03
- **지목** 서지오
- **수법 진술** 오토빌레이 제동 캠을 무력화하고 점검일지를 조작한 뒤, 안전요원을 위장 메시지로 자리에서 비키게 만들어 피해자가 혼자 시험 등반을 하다 추락하게 했다.
- **동기 진술** 피해자의 시그니처 루트 도면을 도용해 후원계약 제안서에 자신의 이름으로 제출한 사실이 드러날 위기에 몰려 피해자를 살해했다.
