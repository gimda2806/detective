**받아 갈 것 — 검사기를 보는 세션에게 (값어치 순)**

**① `NEIGHBOR_TWIN`은 폴백이 침묵하면 통째로 잠든다. 이번에 실측으로 나왔다.**

CASE134와 CASE135는 **무대와 이름만 다른 같은 사건**이다 — 단계 사슬이 글자까지
같고, 타임라인 열한 항목이 같은 순서이고, `L05`·`E03`·`R01`·`R02`가 전부 같은
자리이며, 엔딩은 문단 순서까지 같았다. 뼈대 문장으로 재면 **서른세 줄**이 같다.

**그런데 `NEIGHBOR_TWIN`이 한 건도 안 걸리고 있었다.** 축 다섯 중 셋이 필요한데:

| 축 | 걸렸나 | 왜 |
| --- | --- | --- |
| 수법 계열 | 아니오 | **양쪽 다 선언이 없고 폴백이 두 편 다 아무 칸에도 안 걸었다** |
| 동기 계열 | 아니오 | **폴백이 CASE135의 동기를 아예 분류하지 못했다** |
| 진입 시각 | 아니오 | 05:30 / 23:45 |
| 단계 이름 | 예 | |
| 인물 배치 | 예 | |

둘뿐이라 문턱에 하나가 모자랐다. **여덟 칸을 선언하자 축이 넷이 되어 경고가
떴다.** 즉 **코퍼스에서 가장 닮은 쌍이 폴백의 침묵 때문에 조용히 지나가고
있었다.**

**볼 만한 것 둘.**

- **「폴백이 아무 칸에도 못 걸었다」와 「겹치지 않는다」가 지금 구별되지 않는다.**
  `checkNeighborTwin`은 `neighborMethodSet`이 빈 집합이면 그냥 겹침 0으로 넘어간다.
  **양쪽 다 빈 집합인 쌍**은 그 축이 판정 불가인 것이지 다른 것이 아니다.
  세어 보면 그런 쌍이 얼마나 되는지 나올 것이고, 많다면 이 검사는 지금
  **선언된 사건에서만 제대로 돈다.**
- **단계 사슬이 글자까지 같은 쌍은 축 하나로도 셀 만하다.** `RANGE_TWIN`이
  사슬 전체를 보는데 조건이 「±10 안에 넷 이상」이라 쌍은 못 센다.
  「이웃 쌍에서 사슬 **전체**가 같으면 그것만으로 센다」가 값싼 보강으로 보인다 —
  이번 쌍은 `initial → admits_confrontation → admits_night_message →
  full_confession`이 통째로 같았다.

**② 폴백이 다섯 편에서 열 군데를 틀리거나 놓쳤다.** 패치 목록은
`docs/archetype-gaps.md`의 「CASE132~136 회차」 끝에 다섯 줄로 정리해 뒀다.
특히 **수법이 세 편에서 아무 칸에도 안 걸렸다**(메탄올 밀주 / 관봉인기 끼임 /
방음 부스 산소 결핍). 그리고 **동기 폴백이 「발각될 위기」를 전부
`secret_exposure`로 읽는 버릇**이 CASE132에서 드러났다 — 추궁당한 것과 폭로
예고를 들은 것은 다르다.

**③ `OPENING_SCENE_MISSING_INCIDENT`가 오프닝 수정을 한 번 막았다.** CASE133의
사망 시각 모순을 고치면서 「숨을 거두었다」를 빼자 그 error가 났다. **발견된 때와
죽은 때를 가르되 발견·사망 낱말 자체는 문면에 남겨야 한다** — 같은 모순
(CASE124류)을 고치는 다음 세션이 같은 데서 걸릴 것이다.
