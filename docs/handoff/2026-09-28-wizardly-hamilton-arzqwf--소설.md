## 첫 번째 — `audit:duplication` 상위 15에 있으면 그것이 회차의 절반이다. 그리고 내역은 출력에 없다

**열 때 `npm run audit:duplication`을 돌려 그 번호가 상위 15에 있는지 먼저 볼 것.**
있으면 README 「이 회차가 할 일」이 도는 회차다(소설만 다르게 쓰고 넘어가지 않는다).

**출력은 어느 문장이 걸린 것인지 안 알려 준다** — 필드별 상위 3과 사건별 비율뿐이다.
스크립트 앞 169줄(집계까지)을 떼고 뒤에 필터를 붙이면 나온다:

```bash
head -169 scripts/audit-duplication.mjs > /tmp/dup.mjs
cat >> /tmp/dup.mjs <<'EOF'
for (const [cid, p, k] of seen) {
  if (cid !== process.argv[2]) continue;
  const n = all.get(k)?.size ?? 1;
  if (n >= MIN_CASES) console.log(`[${n}건] ${p}\n   ${k}`);
}
EOF
node /tmp/dup.mjs CASE367
```

**목록을 읽고 나서야 보인 두 가지.**

1. **`verbal_tic`은 선언이 3건이어도 어구는 13건일 수 있다.** 「'장부상으로는'을 앞세운다」
   선언이 같은 사건은 셋인데 `grep -l 장부상으로는`은 **열셋**이다. **선언을 고칠 때
   `grep`으로 어구를 따로 셀 것.** 그리고 CLAUDE.md 그대로 **어구가 박힌 대사
   (`pressure_responses[0]`)와 그 어구를 부르는 `formality_register`까지 같이** 고쳐야
   선언과 대사가 안 어긋난다(이 편은 셋을 같이 고쳤다).
2. **한 사건 안의 겹침은 어느 검사도 안 센다.** `audit:duplication`은 사건 **사이**만 본다.
   CASE366에는 `CH03`·`CH04`의 `pressure_responses`에 **똑같은 문장**이 있었고,
   `CH01`·`CH03`의 `comic_tell`이 둘 다 「손가락으로 허공에」, `CH03`·`CH04`의
   `knowledge_limits`가 같은 문장, `REL04`·`REL05`의 `public_face`가 「손발이 잘 맞는」/
   「손발을 맞춰 가는」이었다. **3건 목록을 고치는 김에 그 사건 안을 `sort | uniq -d`로
   한 번 훑을 것.**

**「원문을 살린다」(README 쓰는 규칙 2번)와 부딪히지 않는다** — 순서로 푼다. 마스터를 먼저
고치고 소설은 고친 뒤의 원문을 살린다. 거꾸로 하면 존재하지 않는 원문을 인용한 소설이 된다.

## 두 번째 — 진입 시각이 타임라인 항목과 겹치는지를 열 때 본다

앞 회차가 `preEntry`의 `idx === -1` 구멍을 적어 두었다(진입 시각이 `actual_timeline` 항목과
안 겹치면 타임라인 시각 전부가 회상 집합이 되어 그 시각을 쓴 장이 흐름 검사에서 빠진다).
**CASE366은 반대였다** — 진입이 「사건 당일 15:00」이고 `T08`도 15:00이라 `idx`가 잡히고
회상 집합이 넷으로 좁혀져서 **장 제목 열여섯이 하나도 안 빠진 채 재어졌다.**

```bash
jq -r '.opening_scene.detective_entry_time, (.actual_timeline[]|.time)' data/pending-cases/<ID>/<ID>.master.json
```

**겹치면 빠지는 장이 0장, 안 겹치면 타임라인 시각을 제목에 쓴 장 전부다.** 그리고 겹치는
경우에는 **1장 제목을 진입 시각과 같게 두는 것이 가장 싸다** — `ENTRY_TIME_MISMATCH`가
`first.hour !== entry.hour` 에서 바로 빠진다. CASE366은 1장을 「오후 3시」로 두고 그 장
안에서 발견 시각(오후 3시 42분)까지 갔다.

「이상 없음」이 「검사가 돌았다」인지는 셋으로 재었다 — 5장 제목 앞당겨 `TIME_BACKWARD`,
1장 제목을 진입보다 늦춰 `ENTRY_TIME_MISMATCH`, 본문 한 곳을 「두 시」로 바꿔
`TIME_NATIVE_NUMERAL`. 셋 다 되돌리고 `diff`로 확인했다.
