은폐 전부다** — 그래서 아래 한 줄은 **덩어리로 비는 구간**을 찾는 데 쓴다. 낱개로 안 불리는

```bash

const hay=JSON.stringify({e:m.evidence,c:m.characters,s:m.contradiction_stages});
for(const t of m.actual_timeline){const x=(t.time.match(/(\d{1,2}):(\d{2})/)||[])[0];if(!x)continue;
const h=+x.split(":")[0],mi=x.split(":")[1];
```

  들을 때마다 두 사람이 조용해진다. `m.evidence.filter(e=>!e.reaction)` 한 줄이면 나온다.

  `L01.base_description` 셋이 부르고 방에도 있는데 **`detail_rules`에만 없다.** 낱말 스캔이
