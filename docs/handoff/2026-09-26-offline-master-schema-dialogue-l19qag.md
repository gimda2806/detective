## 판본 루틴이 생겼다 (소설 루틴·생성 루틴에)

- `npm run audit:offline`(`scripts/audit-offline-readiness.mjs`) — 원본이 오프라인 필수 표를 얼마나
  갖췼는지 번호순으로 센다. 판본이 있으면 판본을 본다. 「다음 게이트까지 비는 번호」가 판본 루틴의
  입력이다(지금 014·015·016). 지침 `docs/offline-version-routine.md`, CLAUDE.md 「이 세션 밖에서
  도는 루틴」에 한 줄.
- **소설 루틴에**: 판본 루틴은 소설 끝의 「오프라인으로 옮길 것」을 설계도로 읽는다. 「보드로」 갈래가
  없는 편(2026-09-26 전 소설 전부)은 판본이 보드를 새로 쓰고 **소설에 덧붙이지 않는다**(판본 노트에
  적는다). 앞으로 쓰는 소설에는 「보드로」 갈래를 붙여 주면 판본 작업이 절반으로 준다.
- **생성 루틴에**: 생성 스펙이 오프라인 필수 표(`points_finger`·`comic_tell`·`points_at`·`mismatch`·
  보드·`suggested_by`/`cue`·헛다리 `weight`·`access_level`/`connects_to`)를 한 칸도 요구하지 않는다
  (2026-09-26 실측 — `voice_profile`만). 새 원본이 오프라인 완제품으로 태어나게 스펙을 고치고 새
  원본에 error로 거는 안은 **사용자가 아직 결정하지 않았다**(2·3만 진행). 스펙을 먼저 고치고 검사를
  한 박자 뒤에 올리는 순서가 안전하다 — 검사를 먼저 올리면 생성 루틴의 다음 PR들이 빨개진다.
