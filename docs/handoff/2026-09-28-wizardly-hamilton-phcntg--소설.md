## 환경

`npm ci`는 **여섯 회차 연속** 그냥 된다(3분쯤). `check:case`·`check:offline`·`check:novel` 셋 다 돈다.
열자마자 돌리고 넘어갈 것.

`check:case CASE371`(errors 0, warnings 1) → `check:offline CASE371`(완주 1, 보드 네 칸 확정,
**114.0턴**, 텍스트 이상 0) → `check:novel`(errors 0, warnings **466** — `TIME_NOT_IN_MASTER` 353 ·
`TIME_UNRECORDED` 85 · `TIMELINE_AFTER_ENTRY_UNUSED` 28). **세 회차 연속 코드별로 같은 값이다** —
새 소설이 셋 다 0으로 들어오면 총계는 안 움직인다. **총계만 보고 「안 늘었다」로 읽지 말 것.**
총계가 움직였으면 어느 편인지부터: `npm run check:novel 2>&1 | grep -B2 TIMELINE_AFTER_ENTRY_UNUSED | grep '\.md$'`

`check-novel-time.mjs CASE371.md`는 **errors 0 · warnings 0 · info 0**이고, 「이상 없음」이 「검사가
돌았다」인지는 셋으로 쟀다(7장 제목 앞당겨 `TIME_BACKWARD` · 1장 제목 늦춰 `ENTRY_TIME_MISMATCH`+
`TIME_BACKWARD` · 「새벽 5시 58분」을 「새벽 다섯 시 58분」으로 바꿔 `TIME_NATIVE_NUMERAL`. 셋 다
되돌리고 `diff`로 확인). `ids CASE371 fix` 고칠 것 없음. `build:source`는 마스터를 안 고쳤으므로,
`tsc`는 코드를 안 고쳤으므로 돌리지 않았다.

처리했으면 이 파일을 지운다.
