# 탐정·한지우 주고받기 — 쓸 자리 목록

오프라인 GM(`app/gm/offline-engine.ts`)에서 두 사람이 **서로에게** 말하는
자리는 지금 둘뿐이다 — 증거를 찾은 순간(`BANTER_DISCOVERY`, 19쌍)과
「막혔어요」(`HINT_BANTER`, 6상황 × 4쌍). 나머지 27개 풀은 전부 한쪽만
말하고 끝난다. 가장 아픈 자리가 단계 돌파다: `DETECTIVE_BREAK`와
`JIWOO_BREAK`가 같은 턴에 같이 나오는데 **따로 뽑히므로 서로 답을 하지
않는다.**

이 문서는 그 자리들을 채우기 위한 것이다. 쌍을 여기 쓰면
`offline-engine.ts`의 풀로 옮겨 붙인다.

---

## 공통 규칙 (전부 코드에 이미 적혀 있는 것)

1. **말투 비대칭.** 탐정은 한지우에게 반말, 한지우는 탐정에게 반존대(`-요`).
   이건 명시적으로 유지 결정된 것이라 바꾸지 않는다.
2. **한지우는 판단하지 않는다.** 방금 벌어진 것을 되짚거나 핀잔을 줄 뿐,
   **다음에 누구를 볼지 고르지 않고** 무엇이 해결됐다고 선언하지 않는다.
3. **한 번뿐인 과거 사건을 넣지 않는다.** "어제 우산은 못 찾으셨으면서"가
   311건에 돌아가면 탐정은 매 사건마다 어제 우산을 잃어버린 사람이 된다.
   관계의 이력(`탐정님 펜은 늘 제가 찾아드리는데`)이나 한지우 자신의
   배경(`제가 회사 다닐 때`)은 매번 참이라 괜찮다.
4. **사건 내용을 넣지 않는다.** 인물 이름·장소 이름·카드 제목·시각이
   들어가면 그 사건에서만 맞는 대사가 된다. 311건 전부에서 참이어야 한다.
5. **`lead`가 누가 먼저 여는지를 정한다.** 한 자리 안에서 두 방향이 섞여야
   관계가 한 방향으로 굳지 않는다 — 탐정이 지시하고 한지우가 되받는 박자와,
   한지우가 찌르고 탐정이 받아치는 박자 둘 다 필요하다. 대략 반반.
6. **자리당 6~8쌍.** 주고받기는 한마디보다 훨씬 빨리 닳는다. 두 줄짜리
   대화는 두 번째 보면 바로 "아까 그거"가 된다.

형식:

```ts
{ lead: 'jiwoo',     jiwoo: '"…"', detective: '"…"' },
{ lead: 'detective', jiwoo: '"…"', detective: '"…"' },
```

`lead: 'jiwoo'`면 한지우 줄이 먼저 찍히고 탐정이 받는다. 반대도 같다.

# 지금 쓸 자리 넷

## A. 단계 돌파 — `BANTER_STAGE_BREAK` (8쌍)

**가장 먼저.** 이 게임의 클라이맥스인데 지금 두 사람이 각자 허공에 말한다.

- **언제**: 증거를 들이대서 상대의 말이 바뀐 순간. 카드 여러 장을 늘어놓은
  턴이면 늘어놓기 → 다그침 → 상대의 새 진술 뒤에 붙는다.
- **지금**: `DETECTIVE_BREAK` 3줄 + `JIWOO_BREAK` 6줄이 따로 뽑힘.
- **쓸 수 있는 것**: 방금 말이 바뀌었다는 사실, 탐정이 맞았다는 것,
  아직 끝이 아니라는 것, 받아 적는 일.
- **쓰면 안 되는 것**: 누가 범인인지 암시, 다음에 무엇을 할지, 인물 이름.
  ("이제 저 사람이 범인이네요" 같은 줄은 규칙 2번 위반이면서 스포일러다.)

예시 두 쌍(톤 기준으로만 — 바꾸셔도 됩니다):

```ts
{ lead: 'detective',
  jiwoo: '"…지금 말씀이 아까랑 다르네요. 둘 다 적겠습니다."',
  detective: '"둘 다 적어. 어느 쪽이 참인지는 나중에."' },
{ lead: 'jiwoo',
  jiwoo: '"방금 숨 한 번 쉬신 데, 거기도 적을까요?"',
  detective: '"적어. 말보다 그게 정확할 때가 있어."' },
```

빈 슬롯 6쌍:

```ts
{ lead: '', jiwoo: '""', detective: '""' },
{ lead: '', jiwoo: '""', detective: '""' },
{ lead: '', jiwoo: '""', detective: '""' },
{ lead: '', jiwoo: '""', detective: '""' },
{ lead: '', jiwoo: '""', detective: '""' },
{ lead: '', jiwoo: '""', detective: '""' },
```

## B. 헛다리 해소 — `BANTER_HERRING_CLEAR` (6쌍)

- **언제**: 한 사람의 의심이 벗겨진 순간(`cleared`). 마스터의 해명
  (`actual_reason`)이 나온 직후.
- **지금**: `JIWOO_HERRING_CLEAR` 6줄만. 탐정은 자기가 틀렸던 것에 대해
  **아무 말도 안 한다.**
- **쓸 수 있는 것**: 한 명 줄었다는 것, 의심했던 데 대한 겸연쩍음,
  줄어든 게 반가운 건지 모르겠다는 감각, 지운 이유도 기록이라는 것.
- **쓰면 안 되는 것**: 남은 사람이 누구인지, 이제 누구를 봐야 하는지.

예시 한 쌍:

```ts
{ lead: 'jiwoo',
  jiwoo: '"…이 분은 아니었네요. 사과는 제가 대신 못 해 드립니다."',
  detective: '"사과할 일은 아니야. 물어봐야 아는 거니까."' },
```

빈 슬롯 5쌍.

---

## C. 헛짚음 · 빈손 — `BANTER_DEAD_END` (8쌍)

헤매는 구간이야말로 둘이 붙어 있는 게 보여야 하는 자리다. 빈도가 제일
높으므로 여기만 8쌍.

- **언제**: 제시가 안 먹혔거나(`NPC_DEFLECT`), 뒤졌는데 아무것도 없을 때
  (`NOTHING_FOUND`).
- **지금**: `INSIGHT_WRONG_DOOR`·`INSIGHT_NOTHING_THERE`·`JIWOO_DEFLECT`·
  `JIWOO_NOTHING`이 전부 따로.
- **쓸 수 있는 것**: 없다는 것도 정보라는 것, 서로 핀잔, 다시 해보자,
  탐정의 헛다리를 한지우가 놀리는 것.
- **쓰면 안 되는 것**: **어디를 가라거나 무엇을 보라는 지시.** 그건
  힌트 버튼 몫이고, 여기서 하면 규칙 2번 위반이다.

예시 한 쌍:

```ts
{ lead: 'jiwoo',
  jiwoo: '"안 통했네요. 표정은 그대로 유지하세요."',
  detective: '"유지하고 있어."' },
```

빈 슬롯 7쌍.

---

## D. 사건을 닫고 나서 — `BANTER_AFTER_CLOSE` (6쌍)

지금 주고받기가 **아예 없는** 자리다.

- **언제**: 사건 종결. 마스터의 `ending_scene` 서술이 끝난 뒤 맨 마지막.
- **주의**: 마스터의 엔딩이 이미 두 사람의 대사로 끝나는 사건이 많다
  (CASE014는 계단 삐걱거리는 소리로 끝난다). **그 위에 얹는 것이므로
  사건을 요약하거나 마무리 짓는 말이면 안 된다** — 이미 끝난 이야기를
  한 번 더 끝내는 꼴이 된다. 사건이 아니라 **일이 끝난 것**에 대해 말한다.
- **쓸 수 있는 것**: 피곤함, 수첩 정리, 밥·퇴근, 다음 일, 아무 말 없이
  같이 걷는 것.
- **쓰면 안 되는 것**: 사건 요약, 범인 언급, 교훈.

예시 한 쌍:

```ts
{ lead: 'jiwoo',
  jiwoo: '"오늘 건 정리하는 데 좀 걸리겠는데요."',
  detective: '"천천히 해. 어차피 나도 오늘은 여기까지야."' },
```

빈 슬롯 5쌍.

# 그 다음 (엔진에 트리거를 먼저 넣어야 하는 것)

쓰실 거면 이것도 받아 두겠습니다. 다만 **A~D가 먼저**입니다 — 아래는
지금 엔진이 반응하지 않는 상태라, 대사보다 코드가 먼저 필요합니다.

| 자리 | 언제 | 필요한 코드 |
|---|---|---|
| `BANTER_SAME_ROOM_AGAIN` | 같은 방을 세 번째 들어옴 | `location_visit_counts`가 `GameState`엔 있고 `EngineState`엔 없다. 한 줄 추가 |
| `BANTER_CARD_UNUSED` | 카드를 얻고 오래 아무에게도 안 냄 | 획득 턴 수 기록 |
| `BANTER_HINT_AGAIN` | 힌트를 연달아 누름 | `hint_log.length`로 바로 됨 |
| `BANTER_NPC_EXHAUSTED` | 한 사람에게서 더 들을 게 없음 | 이미 판정 있음(`NPC_SPENT` 근처) |
| `BANTER_FIRST_MEETING` | 사람을 처음 만남 | 이미 자리 있음(`JIWOO_INTERVIEW_START`) |
