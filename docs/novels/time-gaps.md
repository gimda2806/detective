# 소설이 지어낸 시각 — 마스터가 놓친 타임라인인가

`npm run check:novel`의 `TIME_UNRECORDED`(마스터에도 소설의 「보탠 것」에도 없는
시각) 37건을 2026-09-20에 하나씩 대조한 결과다. 처음엔 「마스터가 비워 둔 자리를
소설이 메운 것」으로 넘겼는데, **어긋나지 않았다는 것과 메워도 되는 자리였다는
것은 다르다**(사용자 지적). 소설은 이주의 설계도라 지어낸 시각은 「오프라인으로
옮길 것」에 적혀야 하고, 거기 없으면 마스터가 놓친 것이라도 아무도 되먹이지
못한다.

네 갈래로 나눴다. **A와 B가 마스터로 되먹일 것**이고, C는 소설을 마스터에 맞출
것, D는 그대로 두어도 되는 것이다. 마스터를 고치는 것은 이주 루틴(회차 단위로
사건을 읽고 다시 쓰는 쪽)의 몫이라 여기서는 목록만 세운다 — 진상은 어느 줄도
건드리지 않아도 된다.

## A. 마스터 타임라인에 없는 인물의 움직임 — `actual_timeline` 항목 후보

「누가 언제 어디 있었나」가 사건의 판정(알리바이·기회)에 걸리는데 마스터에는
그 시각이 없는 자리다. 소설이 지어낸 값을 그대로 옮기면 된다.

| 사건 | 시각 | 무엇 | 왜 빈 칸인가 |
| --- | --- | --- | --- |
| CASE019 | 06:20 | 표건우(CH02) 도착. 7시 협의, 분재원에서 1시간 반 | **`R01.how_to_clear`가 「방문 예약 기록·도착 시각을 대조한다」고 부르는데 마스터에 그 시각이 없다.** 카드도 진술도 없어 소설이 통째로 만들었다. 헛다리를 푸는 근거가 마스터 밖에 있다 |
| CASE063 | 20:40 | 강준유(CH01) 퇴장 | `E06`이 「사고보다 한 시간 앞서」라고만 적고, 타임라인에 CH01 퇴장 항목이 없다. `T04`(20:10, 백호유가 직접 알린다) 뒤여야 한다 |
| CASE064 | 20:25 | 유서용(CH01) 퇴장 | 같은 자리. 원래 「두 시간 앞서」(≈19:35)로 `T04` 20:10과 충돌해 2026-09-20에 「한 시간 남짓」으로 고쳤다. 시각은 여전히 마스터에 없다 |
| CASE065 | 20:30 | 선서솔(CH01) 퇴문 | 같은 자리 |
| CASE066 | 20:40 | 염찬민(CH01) 퇴관 | 같은 자리 |
| CASE067 | 20:40 | 편예광(CH01) 퇴장 | 같은 자리. 22:50 재입장은 소설 「보탠 것」 6번에 이미 있다 |
| CASE066 | 05:55 | 송채민(CH03, 진범)이 새벽 재출입 뒤 나간 시각 | `T08`(05:40 재출입)은 있는데 나간 항목이 없다. `E03`「새벽 재출입 기록」에도 시각이 없다 |
| CASE007-ver2 | 06:50 | 배시완(CH04)이 앰플 재고를 세어 보고 올린다 | 진입 06:30 뒤의 일. `E03`(앰플 두 개 사라짐)이 발견되는 경로인데 타임라인은 `T08` 06:30 발견에서 끝난다 |
| CASE007-ver2 | 23:15 | 노현석(CH01)이 22:30·23:00·23:15 순찰 때마다 로비에 있었다 | 노현석의 알리바이다. `T05`(22:30 로비)만 있고 `T06`(23:00 투여) 시각을 덮는 항목이 없다. `E09`(순찰 동선)에도 그가 로비에 있었다는 말이 없다 |
| CASE044 | 10:30 | 강필도(CH?)가 진검 소품을 점검했다 | `T08`이 「당일 오전」이라 시각이 없다. 알리바이가 아니라 「그 시점엔 이상이 없었다」의 시점이라 숫자가 있어야 `T09` 13:00 손질과 견줄 수 있다 |
| CASE034 | 22:20 | 임수혁이 여과실에 들어간 시각(정비 시작) | `T05`는 23시(정비 마침)만 있다. 소설은 22:20 입실·23:00 통과로 정비 구간을 세웠다 |
| CASE062 | 22:10 | 컨베이어가 22:10까지 돌았다 | `T06` 21:40 추락 뒤 30분을 라인이 더 돌았다는 뜻인데, 누가 멈췄는지 마스터에 없다. `T08` 22:15 「한범인의 동선은 평소와 다를 바 없어 보인다」 바로 앞이라 은폐 동작일 수 있다 — **확인 필요** |

## B. 마스터 카드가 시각 없이 말하는 기록 — `evidence[].content`에 시각을 박을 후보

카드는 있는데 「14시 무렵」·「어젯밤」처럼 뭉개져 있어 플레이어가 타임라인과
눈으로 맞춰 볼 수 없는 자리다. 시각이 곧 단서라는 CLAUDE.md 규칙이 카드에도
든다.

| 사건 | 카드 | 소설이 박은 시각 | 비고 |
| --- | --- | --- | --- |
| CASE048 | `E08` 노을담의 통화 기록 「14시 무렵」 | 14:03 시작, 11분 | **`T06` 14:10 추락과 겹치는 알리바이**인데 「무렵」으로는 겹치는지 알 수 없다 |
| CASE034 | `E01` 차현우의 사진 | 어제 16:22 | `T01` 「전날 오후」 |
| CASE034 | `E08` 여지호의 새벽 목격담 | 순찰 일지 02:40·03:20·04:00·04:40 | `T07` 4시 언성을 들은 근거가 「순찰 중」뿐이다. CASE036 소설이 예성구에게 순찰 일지를 놓아 준 것과 같은 자리 |
| CASE007 | 출입기록 단말(`E06` 경비원 진술이 대신 말한다) | 23:02 한소율 IN, 23:28 서지훈 OUT | `T06` 23:00·`T07` 23:30의 기록 자국. 카드가 진술이라 단말 기록 자체는 마스터에 없다 |
| CASE066 | `E03` 새벽 재출입 기록 | 05:40 열림 → 05:55 닫힘 | A의 05:55와 같은 자리 |
| CASE060 | `E04` 퍼지 시퀀스 로그 「22시경 중단」 | 22:01 시작 → 22:18 중단, 17분 | 「절반도 안 돼요」가 성립하려면 예정 길이도 있어야 한다 |
| CASE054 | `E05` 조제실 CCTV 「20:40경 대화」 | 20:51 종료, 11분 | 낮음 |
| CASE047 | `T14` 사진 「20:00~20:30」 | 20:02·08·11·17·19·24·28 | 구간이 이미 있어 낮음 |

## C. 마스터에 있는 사건인데 소설의 시각이 몇 분 어긋난다 — 소설을 맞출 것

같은 사건을 두 시각으로 부르면 플레이어(독자)가 두 시각을 맞춰 볼 수 없다.
마스터를 고칠 것이 아니라 소설을 마스터 숫자로 되돌리면 된다.

| 사건 | 소설 | 마스터 | 비고 |
| --- | --- | --- | --- |
| CASE060 | 21:41:12 스크립트 실행 | `T06` 21:40 | 로그 줄의 초 단위 연출. 21:40:12로 바꾸면 그대로 산다 |
| CASE094 | 07:04 정수완 캡처 | `T11` 07:00 | 탐정이 옆에서 지켜본 같은 순간 |
| CASE007 | 21:10 「그게 몇 시쯤이었어요」의 답 | `T02` 21:00 | 한소율이 원장실에 온 시각 |

| CASE005 | 21:15·21:30·21:45 | `E01`이 「15분마다」라고 이미 적었다. 풀어 쓴 것 |
| CASE028 | 05:30 주다인 창고 기록 | 진입(05:25) 뒤의 서사 박자. 판정에 걸리지 않는다 |

## 다음에 새 소설을 쓸 때

지어낸 시각은 **쓰는 자리에서 바로** 「오프라인으로 옮길 것」 표에 한 줄 넣는다.
그러면 `TIME_UNRECORDED`가 `TIME_NOT_IN_MASTER`로 내려가고, 이 문서에 줄이 늘지
않는다. 위 A·B를 마스터로 옮긴 회차는 이 문서의 그 줄을 지운다 — 남은 줄이 곧
미처리 목록이다.
